使用场景

稠密的线性层。因此排除了embedding层和分类层。

计算

总体上和momentum类似。但是，在更新前对更新量做一下NewtonSchulz5操作。其中参数G是更新量。

def newtonschulz5(G, steps=5, eps=1e-7):
    assert G.ndim == 2
    a, b, c = (3.4445, -4.7750, 2.0315)
    X = G.bfloat16()
    X /= (X.norm() + eps)
    if G.size(0) > G.size(1):
        X = X.T
    for _ in range(steps):
        A = X @ X.T
        B = b * A + c * A @ A
        X = a * X + B @ X
    if G.size(0) > G.size(1):
        X = X.T
    return X

苏剑林的博客里面写的是（WWW是参数矩阵，对应上面的θ\thetaθ）： Wt=Wt−1−ηt[msign(Mt)+λWt−1] W_t = W_{t-1} - \eta_t [\mathrm{msign}(\boldsymbol M_t) + \lambda W_{t-1}] Wt​=Wt−1​−ηt​[msign(Mt​)+λWt−1​] 则是加了梯度衰减的版本，类似Adam变成AdamW。

Deriving Muon当中写的是： W←W−η×fan-outfan-in×NewtonSchulz(∇WL). W \gets W - \eta \times \sqrt{\frac{\texttt{fan-out}}{\texttt{fan-in}}} \times \mathrm{NewtonSchulz}(\nabla_W \mathcal{L}). W←W−η×fan-infan-out​​×NewtonSchulz(∇W​L). fan-out和fan-in分别是输出和输入的维度（参数矩阵WWW的维度）。

推导

本节内容主要直接从Deriving Muon里面抄

“稠密”和RMSNorm

线性层主要处理“稠密”的向量，这里的所谓“稠密”指的是大部分位置的值都接近1或者-1。可以用RMSNorm来量化“稠密性”： ∥v∥RMS:=∥v∥d \|v\|_\text{RMS} := \frac{\|v\|}{\sqrt{d}} ∥v∥RMS​:=d​∥v∥​ 之所以除以d\sqrt{d}d​，是为了兼容不同维数的向量，不管什么维度，“稠密”的向量RMSNorm会在1附近。如果都用L2范数，高维度对应的norm会更大。在Transformer里面，我们几乎每一层Linear后面都要加上LayerNorm，可以理解为为了鼓励稠密性，抑制稀疏性。

那么权重矩阵会怎么影响RMSNorm呢？考虑 y=Wxy = Wxy=Wx，那么 ∥y∥2=yTy=xTWTWx \|y\|^2 = y^Ty = x^TW^TWx ∥y∥2=yTy=xTWTWx 定义RMS到RMS映射的范数如下，意义是矩阵最大能把一个向量缩放到什么程度。 ∥W∥RMS→RMS:=max⁡x≠0∥y∥RMS∥x∥RMS=dxdy⋅max⁡x≠0∥Wx∥∥x∥ \|W\|_\mathrm{RMS\to RMS} := \max_{x\ne 0}\frac{\|y\|_\mathrm{RMS}}{\|x\|_\mathrm{RMS}} = \sqrt{\frac{d_x}{d_y}}\cdot \max_{x\ne 0}\frac{\|Wx\|}{\|x\|} ∥W∥RMS→RMS​:=x=0max​∥x∥RMS​∥y∥RMS​​=dy​dx​​​⋅x=0max​∥x∥∥Wx∥​ 所以其实就是WTWW^TWWTW的最大特征值，即WWW最大奇异值的平方，即WWW的谱半径ρ(W)\rho (W)ρ(W)。∥y∥\|y\|∥y∥永远不会比ρ(W)∥x∥\rho(W)\|x\|ρ(W)∥x∥大。dxd_xdx​和dyd_ydy​分别是x和y的维度，其实就是原公式的fan-in和fan-out。

于是，考虑用ΔW\Delta WΔW更新参数后，线性层输出的变化： Δy=(W+ΔW)x−Wx=ΔWx \Delta y = (W+\Delta W)x - Wx = \Delta W x Δy=(W+ΔW)x−Wx=ΔWx 会有 ∥Δy∥RMS≤∥ΔW∥RMS→RMS⋅∥x∥RMS \|\Delta y\|_{\mathrm{RMS}} \le \|\Delta W\|_\mathrm{RMS\to RMS} \cdot \|x\|_\mathrm{RMS} ∥Δy∥RMS​≤∥ΔW∥RMS→RMS​⋅∥x∥RMS​

参数更新的效率

我们希望参数更新之后，loss下降最多。考虑每个参数WijW_{ij}Wij​，我们希望最小化更新后的loss，即L(W+ΔW)\mathcal L(W + \Delta W)L(W+ΔW)。同时希望输出维持稠密性，即稠密性的变化要控制在阈值η\etaη以内。为了方便，我们把L(W+ΔW)\mathcal L(W + \Delta W)L(W+ΔW)泰勒展开到一阶，忽略高阶项 min⁡ΔWijL(W)+∂L(W)∂WijΔWs.t. ∥Δy∥RMS≤η \begin{aligned} & \min_{\Delta W_{ij}} \mathcal L (W) + \frac{\partial \mathcal L(W)}{\partial W_{ij}}\Delta W \\ \mathrm{s.t.\ } & \|\Delta y\|_{\mathrm{RMS}} \le \eta \end{aligned} s.t. ​ΔWij​min​L(W)+∂Wij​∂L(W)​ΔW∥Δy∥RMS​≤η​ 把所有WijW_{ij}Wij​写到一块之后就是，并且注意到L(W)\mathcal L(W)L(W)在这里相对于ΔW\Delta WΔW是个常数，问题变为最小化这两个矩阵的Frobenius内积 min⁡ΔW⟨∇WL,ΔW⟩ \min_{\Delta W} \langle \nabla_W \mathcal L, \Delta W\rangle ΔWmin​⟨∇W​L,ΔW⟩ ∥x∥RMS\|x\|_{\mathrm{RMS}}∥x∥RMS​也和ΔW\Delta WΔW无关，问题变成 min⁡ΔW⟨∇WL,ΔW⟩s.t. ∥ΔW∥RMS→RMS≤η′ \begin{aligned} & \min_{\Delta W} \langle \nabla_W \mathcal L, \Delta W\rangle \\ \mathrm{s.t.\ } & \|\Delta W\|_\mathrm{RMS\to RMS} \le \eta' \end{aligned} s.t. ​ΔWmin​⟨∇W​L,ΔW⟩∥ΔW∥RMS→RMS​≤η′​ 然后这一步我暂时不理解怎么证明。但是可以直观感受到，把∇WL\nabla_W\mathcal L∇W​L每个特征向量方向都取−η′-\eta'−η′即可，让他在可控范围内尽量负。或者说，每个特征向量的方向都均等地更新，不因梯度的贡献量而偏袒某个方向。由于梯度不一定是方阵，所以用SVD而不是特征值分解。 ΔW=−η′dxdy⋅UVT \Delta W = -\eta' \sqrt{\frac{d_x}{d_y}} \cdot UV^T ΔW=−η′dy​dx​​​⋅UVT

绕开SVD

在矩阵很大的时候，SVD是个代价比较高的操作。因此需要找到高效的方式计算 ∇WL=UΣVT↦UVT \nabla_W\mathcal L = U\Sigma V^T \mapsto UV^T ∇W​L=UΣVT↦UVT 这个映射就是上面苏剑林博客里的msign(⋅)\text{msign}(\cdot)msign(⋅)函数，可以看作符号函数的推广。

此处的所谓Newton-Schulz方法，核心在于利用奇次矩阵多项式的性质 p(X)=Up(Σ)VT p(X) = Up(\Sigma)V^T p(X)=Up(Σ)VT 相当于直接作用于奇异值。

于是乎作者找到一个多项式 p3(Σ):=32⋅Σ−12⋅ΣΣ⊤Σ. p_3(\Sigma) := \frac{3}{2} \cdot \Sigma - \frac{1}{2} \cdot \Sigma \Sigma^\top \Sigma. p3​(Σ):=23​⋅Σ−21​⋅ΣΣ⊤Σ. 一维情况打出来如下图左。反复应用这个多项式如图右，会发现在±1\pm 1±1附近，趋近于符号函数了。

超参设置

根据苏剑林的说法，如果用Adam迁移到Muon，需要将学习率放大0.2d0.2\sqrt{d}0.2d​倍，一般大约是10倍。所以他们做的moonlight版Muon还在根号前面多乘了0.20.20.2，而且为了方便把根号下的内容改成了fan-in和fan-out中的较大值。
