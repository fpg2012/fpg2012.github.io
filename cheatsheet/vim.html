vim使用速查表

1. 模式（Modes）

命令/快捷键 说明
Esc 或 Ctrl+[ 回到普通模式（Normal）
i / I 在光标前 / 行首进入插入模式
a / A 在光标后 / 行尾进入插入模式
o / O 在下方 / 上方新建一行进入插入模式
v / V 进入可视模式（字符 / 行）
Ctrl+v 进入可视块模式
: 进入命令行模式
R 进入替换模式

2. 光标移动

命令/快捷键 说明
h j k l 左、下、上、右
w / b 下一个 / 上一个单词开头
e / ge 下一个 / 上一个单词结尾
0 / ^ 行首 / 行首第一个非空白字符
$ 行尾
gg / G 文件开头 / 文件结尾
<n>G 或 :<n> 跳到第 n 行
Ctrl+d / Ctrl+u 向下 / 向上翻半页
Ctrl+f / Ctrl+b 向下 / 向上翻整页
% 跳到匹配的括号
{ / } 上一个 / 下一个段落
f<c> / F<c> 行内向后 / 向前跳到字符 <c>
t<c> / T<c> 跳到字符 <c> 之前

3. 编辑与插入

命令/快捷键 说明
x / X 删除光标处 / 光标前一个字符
r<c> 将光标处字符替换为 <c>
s / S 替换字符 / 整行
~ 切换光标处字符大小写
J 合并下一行
. 重复上一次修改
u / Ctrl+r 撤销 / 重做
> / < 增加 / 减少缩进
>> / << 整行增加 / 减少缩进
Ctrl+n 插入模式自动补全

4. 删除、复制与粘贴

命令/快捷键 说明
dd / yy 删除 / 复制整行
<n>dd 删除 n 行
dw / yw 删除 / 复制到下一个单词
d$ / y$ 删除 / 复制到行尾
dG 删除到文件末尾
p / P 粘贴到光标后 / 前
"<reg> 指定寄存器，如 "ayy
"+y / "+p 复制到 / 粘贴自系统剪贴板
:%d 删除全文

5. 搜索与替换

命令/快捷键 说明
/pattern / ?pattern 向后 / 向前搜索
n / N 重复搜索（同向 / 反向）
* / # 向后 / 向前搜索光标下的单词
:noh 取消搜索高亮
:%s/old/new/g 全文替换
:%s/old/new/gc 全文替换并逐个确认
:s/old/new/ 替换当前行第一个匹配
:n,m s/old/new/g 替换第 n 到 m 行

6. 文件、缓冲区与窗口

命令/快捷键 说明
:w / :q / :wq / :q! 保存 / 退出 / 保存退出 / 强制退出
:e <file> 打开文件
:bn / :bp 下一个 / 上一个缓冲区
:bd 关闭缓冲区
:sp / :vsp 水平 / 垂直分割窗口
Ctrl+w w 在窗口间循环切换
Ctrl+w h/j/k/l 切换到指定方向的窗口
:tabnew / :tabclose 新建 / 关闭标签页
gt / gT 下一个 / 上一个标签页
:set nu / :set nonu 显示 / 隐藏行号

7. 宏、标记与其它

命令/快捷键 说明
q<reg> … q 录制宏到寄存器 <reg>
@<reg> 执行寄存器中的宏
@@ 重复上一次执行的宏
m<c> / `<c> 设置 / 跳转到标记 <c>
Ctrl+o / Ctrl+i 跳到更早 / 更晚的编辑位置
ga 显示光标处字符编码
:help <topic> 打开帮助
:!<cmd> 执行 shell 命令
ZZ / ZQ 保存退出 / 不保存退出

8. 配置文件（~/.vimrc）示例

" 开启语法高亮与行号
syntax on
set number
set relativenumber

" 使用空格代替Tab，宽度为4
set expandtab
set shiftwidth=4
set tabstop=4

" 搜索时忽略大小写，输入大写时区分
set ignorecase
set smartcase
set incsearch
set hlsearch

" 开启鼠标支持
set mouse=a

" 显示光标行与列
set cursorline
set ruler

" 编码
set encoding=utf-8
set fileencoding=utf-8
  • 所有快捷键默认为普通模式（Normal）。
  • 大部分命令前可加数字表示重复次数，例如 3dd 删除 3 行。
  • 修改 ~/.vimrc 后执行 :source ~/.vimrc 或重启 vim 生效。
