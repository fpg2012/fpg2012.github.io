tmux使用速查表

1. 会话管理

命令/快捷键 说明
tmux 启动新会话
tmux new -s <name> 创建命名会话（<name>为会话名）
tmux ls 列出所有会话
tmux attach -t <name> 附加到指定会话
tmux kill-session -t <name> 终止指定会话
tmux kill-server 终止所有会话
Ctrl+b d 分离当前会话（后台运行）

2. 窗口操作

快捷键 说明
Ctrl+b c 创建新窗口
Ctrl+b & 关闭当前窗口
Ctrl+b p 切换到上一个窗口
Ctrl+b n 切换到下一个窗口
Ctrl+b <number> 切换到指定编号窗口（如 0-9）
Ctrl+b , 重命名当前窗口
Ctrl+b w 列出所有窗口（可视化选择）

3. 面板（Pane）操作

快捷键 说明
Ctrl+b % 垂直分割面板（左右布局）
Ctrl+b " 水平分割面板（上下布局）
Ctrl+b <arrow> 切换到指定方向的面板
Ctrl+b x 关闭当前面板
Ctrl+b z 最大化/恢复当前面板
Ctrl+b Ctrl+<arrow> 调整面板大小（按住Ctrl）
Ctrl+b Space 切换面板布局
Ctrl+b ! 将面板拆分为新窗口

4. 复制模式（类似vim）

快捷键 说明
Ctrl+b [ 进入复制模式
Ctrl+Space 开始选择文本
Enter 复制选中的文本
Ctrl+b ] 粘贴已复制的文本
/ 或 ? 在复制模式中搜索（支持正则）

5. 其他实用操作

快捷键 说明
Ctrl+b ? 查看所有快捷键帮助
Ctrl+b : 进入命令模式（输入tmux命令）
Ctrl+b t 显示时间
Ctrl+b r 重新加载tmux配置（需先修改~/.tmux.conf）

6. 配置文件（~/.tmux.conf）示例

# 设置前缀键为Ctrl+a（默认是Ctrl+b）
set -g prefix C-a
unbind C-b
bind C-a send-prefix

# 启用鼠标支持（滚动、选择面板等）
set -g mouse on

# 设置面板分割快捷键更直观
bind | split-window -h
bind - split-window -v

# 启用256色支持
set -g default-terminal "screen-256color"
  • 所有快捷键基于默认前缀键 Ctrl+b（先按Ctrl+b，再按后续键）。
  • 修改配置后需重启tmux或执行 tmux source-file ~/.tmux.conf。
