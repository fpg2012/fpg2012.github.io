dpkg & apt 使用速查表

1. 更新与升级

命令 说明
sudo apt update 更新软件包索引
sudo apt upgrade 升级已安装的包（不删除包）
sudo apt full-upgrade 升级并允许为解决依赖而增删包
sudo apt dist-upgrade 同 full-upgrade（旧写法）
sudo apt autoremove 删除不再需要的依赖
sudo apt autoremove --purge 删除依赖并清除其配置

2. 安装与卸载

命令 说明
sudo apt install <pkg> 安装软件包
sudo apt remove <pkg> 卸载但保留配置文件
sudo apt purge <pkg> 卸载并删除配置文件
sudo apt reinstall <pkg> 重新安装
sudo apt install ./foo.deb 安装本地 deb 并自动解决依赖
sudo dpkg -i foo.deb 用 dpkg 安装本地 deb（不自动解决依赖）
sudo dpkg -r <pkg> 用 dpkg 卸载
sudo apt-mark hold <pkg> 锁定版本，阻止升级
sudo apt-mark unhold <pkg> 解除锁定

3. 查询与搜索

命令 说明
apt search <kw> 搜索软件包
apt show <pkg> 查看包信息
apt list --installed 列出已安装的包
apt list --upgradable 列出可升级的包
apt-cache policy <pkg> 查看版本与来源仓库
dpkg -l <pattern> 按名称列出已安装包
dpkg -L <pkg> 列出包内的文件
dpkg -S <file> 查询文件属于哪个包
dpkg -s <pkg> 查看包的详细状态

4. 清理与修复

命令 说明
sudo apt clean 清空已下载的包缓存
sudo apt autoclean 只清理过时的包缓存
sudo apt --fix-broken install 修复损坏的依赖
sudo dpkg --configure -a 重新配置未完成的安装
sudo dpkg-reconfigure <pkg> 重新运行包的配置
sudo dpkg -P <pkg> 彻底清除包及其配置

5. 仓库与源

命令 说明
sudo add-apt-repository ppa:<user>/<ppa> 添加 PPA 源
sudo add-apt-repository --remove ppa:<user>/<ppa> 移除 PPA 源
sudo install -Dm644 foo.asc /etc/apt/keyrings/foo.asc 安装第三方源签名密钥
sudo apt update 改动源后重新刷新索引

6. sources.list 示例

deb https://deb.debian.org/debian bookworm main contrib non-free
deb https://deb.debian.org/debian bookworm-updates main contrib non-free
deb https://security.debian.org/debian-security bookworm-security main contrib non-free

# 带 signed-by 的第三方源
deb [arch=amd64 signed-by=/etc/apt/keyrings/foo.asc] https://example.com/apt stable main

7. 常用工作流（recipe）

更新系统

sudo apt update && sudo apt full-upgrade

安装本地 deb

sudo apt install ./foo.deb

修复损坏的依赖

sudo apt --fix-broken install

彻底卸载并清理

sudo apt purge foo && sudo apt autoremove --purge
  • 命令中的 <...> 为占位符，使用时替换为实际内容。
  • apt 是 apt-get / apt-cache 面向用户的前端，脚本中可仍用 apt-get。
  • 优先用 apt install ./foo.deb 而非 dpkg -i，前者会自动补齐依赖。
  • 源列表在 /etc/apt/sources.list 和 /etc/apt/sources.list.d/ 中。
