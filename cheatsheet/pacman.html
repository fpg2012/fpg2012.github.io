pacman使用速查表

1. 安装与卸载

命令 说明
sudo pacman -S <pkg> 安装软件包
sudo pacman -Syu 同步源并升级整个系统
sudo pacman -Sy 只同步源（不要单独用，易致部分升级）
sudo pacman -R <pkg> 卸载
sudo pacman -Rs <pkg> 卸载并删除不再需要的依赖
sudo pacman -Rns <pkg> 卸载、删依赖并删除配置文件
sudo pacman -U <file> 安装本地包
sudo pacman -U --needed <file> 已安装则跳过，不重复安装

2. 查询与搜索

命令 说明
pacman -Ss <kw> 搜索仓库中的包
pacman -Qs <kw> 搜索已安装的包
pacman -Si <pkg> 查看仓库包信息
pacman -Qi <pkg> 查看已安装包信息
pacman -Ql <pkg> 列出包内的文件
pacman -Qo <file> 查询文件属于哪个包
pacman -Q 列出所有已安装包
pacman -Qe 仅列出显式安装的包
pacman -Qdt 列出孤立包
pacman -Qkk <pkg> 校验包内文件

3. 清理与维护

命令 说明
sudo pacman -Sc 清理旧版本包缓存
sudo pacman -Scc 清空全部包缓存
sudo pacman -Rns $(pacman -Qtdq) 删除全部孤立包
sudo pacman -Fy 更新文件数据库
pacman -Fs <file> 在文件数据库中查询文件
sudo pacman-key --init 初始化密钥环
sudo pacman-key --populate archlinux 导入官方密钥

4. 更新系统

sudo pacman -Syu

5. 安装本地包

sudo pacman -U --needed ./foo.pkg.tar.zst

6. 删除孤立包

sudo pacman -Rns $(pacman -Qtdq)

7. 查询文件属于哪个包

pacman -Qo "$(which foo)"

8. 降级 / 回滚软件包

sudo pacman -U /var/cache/pacman/pkg/foo-1.2.3-1-x86_64.pkg.tar.zst

9. 使用 AUR

paru -S <pkg>
paru -Syu

10. 清理包缓存（保留最新）

sudo pacman -Sc
# 或安装 pacman-contrib 后只保留最近几个版本
paccache -r

11. .desktop 文件示例

[Desktop Entry]
Type=Application
Name=Foo
Comment=A demo application
Exec=/usr/bin/foo %U
Icon=foo
Terminal=false
Categories=Utility;Development;
Keywords=foo;demo;
StartupNotify=true

12. PKGBUILD 文件示例

# Maintainer: nth233 <fpg2012@foxmail.com>
pkgname=foo
pkgver=1.0.0
pkgrel=1
pkgdesc="A demo package"
arch=('x86_64')
url="https://example.com/foo"
license=('MIT')
depends=('glibc')
makedepends=('cmake' 'git')
source=("$pkgname-$pkgver.tar.gz::https://example.com/foo/archive/v$pkgver.tar.gz")
sha256sums=('SKIP')

build() {
  cd "$pkgname-$pkgver"
  cmake -B build -DCMAKE_INSTALL_PREFIX=/usr
  cmake --build build
}

package() {
  cd "$pkgname-$pkgver"
  DESTDIR="$pkgdir" cmake --install build
}

13. systemd unit 文件示例

[Unit]
Description=Foo daemon
After=network.target

[Service]
Type=simple
ExecStart=/usr/bin/foo --foreground
Restart=on-failure
User=foo
Group=foo

[Install]
WantedBy=multi-user.target
  • 命令中的 <...> 为占位符，使用时替换为实际内容。
  • 不要单独使用 pacman -Sy 后直接装包，容易造成部分升级；升级始终用 -Syu。
  • 卸载前先用 pacman -Qi <pkg> 看清依赖，避免误删。
  • AUR 需要 paru / yay 等助手，且不受官方支持。
  • makepkg -si 可构建并安装当前目录下的 PKGBUILD。
  • systemd unit 修改后需 sudo systemctl daemon-reload；用户级 unit 放在 ~/.config/systemd/user/，配合 systemctl --user。
  • .desktop 文件放在 /usr/share/applications/ 或 ~/.local/share/applications/。
