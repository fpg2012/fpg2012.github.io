ssh使用速查表

1. 连接与登录

命令 说明
ssh <user>@<host> 登录远程主机
ssh -p <port> <user>@<host> 指定端口登录
ssh <host> <cmd> 登录后执行一条命令
ssh -i <key> <user>@<host> 指定私钥
ssh -t <host> <cmd> 强制分配伪终端（如远端 sudo）
ssh -N <host> 不执行命令，仅建立连接（常用于隧道）
ssh -v <host> 调试连接过程（-vvv 更详细）

2. 密钥管理

命令 说明
ssh-keygen -t ed25519 -C "<comment>" 生成 ed25519 密钥
ssh-keygen -t rsa -b 4096 生成 4096 位 RSA 密钥
ssh-keygen -f ~/.ssh/id_foo 指定密钥文件路径
ssh-keygen -p -f <key> 修改私钥口令
ssh-keygen -y -f <key> 从私钥导出公钥
ssh-copy-id <user>@<host> 把公钥追加到远端 authorized_keys
eval "$(ssh-agent -s)" 启动 ssh-agent
ssh-add <key> 把私钥加入 agent
ssh-add -l 列出 agent 中的密钥
ssh-add -D 清空 agent 中的密钥

3. 端口转发与隧道

命令 说明
ssh -L <lport>:<dst>:<dport> <host> 本地转发：本地端口 → 远端可达地址
ssh -R <rport>:<dst>:<dport> <host> 远程转发：远端端口 → 本地可达地址
ssh -D <port> <host> 动态转发，建立 SOCKS5 代理
ssh -J <jump> <host> 通过跳板机连接
ssh -W <host>:<port> <jump> 经跳板机转发到任意地址
ssh -o ProxyJump=<jump> <host> ProxyJump 的选项写法

4. 文件传输（scp / rsync）

命令 说明
scp <file> <user>@<host>:<dir> 上传文件
scp -r <dir> <user>@<host>:<dir> 上传目录
scp -P <port> ... 指定端口（注意是大写 -P）
scp <user>@<host>:<file> . 下载文件到当前目录
rsync -avz <dir> <host>:<dir> 增量同步
rsync -avz --delete <src> <dst> 镜像同步（删除目标多余文件）
rsync -avz -e "ssh -p <port>" ... rsync 指定 SSH 端口

5. ~/.ssh/config 示例

Host foo
    HostName foo.example.com
    User nth233
    Port 22
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60

Host jump
    HostName jump.example.com
    User nth233

Host bar
    HostName 10.0.0.5
    User root
    ProxyJump jump

6. 常用工作流（recipe）

配置免密登录

ssh-keygen -t ed25519
ssh-copy-id user@host

把本地 8080 转发到远端 80

ssh -N -L 8080:localhost:80 user@host

建立 SOCKS5 代理

ssh -N -D 1080 user@host
# 之后可设置 ALL_PROXY=socks5://localhost:1080

通过跳板机连接内网主机

ssh -J user@jump user@target

把远端目录挂载到本地（sshfs）

sshfs user@host:/remote/path /mnt/point
  • 管理操作均在本地执行；ssh-agent 用于避免重复输入口令。
  • scp 的端口选项是大写 -P，ssh 是小写 -p。
  • authorized_keys 权限应为 600，~/.ssh 应为 700。
  • 首次连接会提示确认主机指纹；StrictHostKeyChecking=no 可跳过但不推荐。
