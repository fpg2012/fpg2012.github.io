pacman / apt 命令对照

1. 系统更新

操作 pacman（Arch） apt / dpkg（Debian）
更新索引 pacman -Sy apt update
升级全部 pacman -Syu apt full-upgrade
查看可升级 pacman -Qu apt list --upgradable

2. 安装与卸载

操作 pacman apt / dpkg
安装包 pacman -S <pkg> apt install <pkg>
安装本地包 pacman -U foo.pkg.tar.zst apt install ./foo.deb
卸载（保留配置） pacman -R <pkg> apt remove <pkg>
卸载并清配置 pacman -Rns <pkg> apt purge <pkg>
删除孤立依赖 pacman -Rns $(pacman -Qtdq) apt autoremove
重新安装 pacman -S <pkg> apt reinstall <pkg>
锁定版本 IgnorePkg（pacman.conf） apt-mark hold <pkg>

3. 查询与信息

操作 pacman apt / dpkg
搜索仓库 pacman -Ss <kw> apt search <kw>
搜索已安装 pacman -Qs <kw> dpkg -l <pattern>
仓库包信息 pacman -Si <pkg> apt show <pkg>
已安装包信息 pacman -Qi <pkg> dpkg -s <pkg>
列出包内文件 pacman -Ql <pkg> dpkg -L <pkg>
文件属于哪个包 pacman -Qo <file> dpkg -S <file>
列出已安装 pacman -Q dpkg -l
仅显式安装 pacman -Qe apt-mark showmanual
校验包文件 pacman -Qkk <pkg> dpkg -V <pkg>

4. 清理与维护

操作 pacman apt / dpkg
清理旧缓存 pacman -Sc / paccache -r apt autoclean
清空缓存 pacman -Scc apt clean
修复依赖 pacman -Syu（必要时 -S <pkg> 重装） apt --fix-broken install
重新配置 — dpkg-reconfigure <pkg>
校验整个系统 pacman -Qkk dpkg -V

5. 软件源与社区

操作 pacman apt / dpkg
源配置文件 /etc/pacman.conf、/etc/pacman.d/mirrorlist /etc/apt/sources.list、/etc/apt/sources.list.d/
包缓存目录 /var/cache/pacman/pkg/ /var/cache/apt/archives/
第三方 / 社区 AUR（paru / yay） PPA / 第三方源
查询文件（含未安装） pacman -F <file> apt-file search <file>
  • 两者都需要 sudo 执行管理操作。
  • pacman 的 -Sy 不要单独使用，升级务必用 -Syu，避免部分升级。
  • apt 的孤立依赖要用 autoremove 清理；pacman 用 pacman -Qtdq 找、-Rns 删。
